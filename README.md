# 2048 · 再走一步

一个使用原生 HTML、CSS 和 JavaScript 开发的 2048 小游戏。低饱和绿色界面，适配电脑和手机，无需安装依赖或构建。

## 运行

直接用现代浏览器打开 `index.html` 即可开始游戏。

也可以在项目目录运行一个本地服务（需要 Python）：

```powershell
python -m http.server 8080
```

随后访问 <http://localhost:8080>。在同一浏览器、同一地址下运行，便于持续保留游戏进度。

## 玩法

- 使用方向键 **↑ ↓ ← →** 或 **W A S D** 移动所有方块。
- 手机在棋盘上向相应方向滑动；电脑也支持鼠标拖动。
- 相同数字沿移动方向相遇时合并，分数增加合并后的数字值。
- 每个方块在一次移动中最多参与一次合并。例如 `2 2 2 2` 向左变成 `4 4`。
- 每次有效移动后，在空位随机生成一个数字：90% 概率为 2，10% 概率为 4。无效移动不会生成方块。
- 达到 **2048** 即获胜，可以选择继续挑战更大的数字。
- 没有空位且无法继续合并时游戏结束。

## 功能

- 当前分数与最高记录。
- 自动保存棋盘和分数，刷新后恢复；数据保存在浏览器本地，不上传服务器。
- 撤销最近一次有效移动（一次机会，撤销后需再次移动才能再撤销）；最高记录不会因撤销降低。
- 随时开始新的一局，保留最高记录。
- 胜利与结束提示、移动端滑动操作、新方块动画。
- 键盘操作、棋盘单元格无障碍标签及分数变化提示；遵循系统减少动画偏好。

如果浏览器禁止本地存储，游戏仍然可以运行，但无法在刷新后保留进度。直接打开文件时，本地存储行为可能因浏览器而异，建议使用上面的本地服务。清除网站数据会删除最高记录与游戏进度。

## 文件结构

```text
2048game/
├── index.html       # 页面结构
├── style.css        # 界面样式与响应式布局
├── engine.js        # 纯函数：移动、合并、结束判断
├── game.js          # 操作、渲染、存档与游戏流程
├── tests/
│   └── engine.test.js # 游戏规则测试
└── README.md
```

## 验证规则

安装 Node.js 后，在项目目录执行：

```powershell
node --test tests/engine.test.js
```

测试覆盖四个移动方向、连续方块合并、计分、无效移动、结束判断及输入不被修改。

## 自定义

在 `style.css` 中调整背景、方块配色与布局；在 `game.js` 的 `spawn()` 中调整新数字的概率。核心合并规则在 `engine.js` 中独立实现，不依赖页面。
